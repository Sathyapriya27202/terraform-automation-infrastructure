# Terraform Automation Infrastructure

Infrastructure as Code (IaC) projects built using Terraform for Microsoft Azure.

## Technologies

- Microsoft Azure
- Terraform
- AKS
- ACR
- Azure Bastion
- Virtual Network (VNet)
- VPN Gateway
- Managed Identity
- Kubernetes

## Projects

Provision Azure networking resources including:
- VNet
- Subnets
- NSGs

### 2. Terraform AKS ACR Infrastructure
Provision:
- Azure Kubernetes Service (AKS)
- Azure Container Registry (ACR)
- Managed Identity

### 3. Terraform Jump VM Bastion AKS
Provision:
- Jump VM
- Azure Bastion
- AKS Cluster

### 4. Terraform VPN VNet Peering
Provision:
- VPN Gateway
- VNet Peering
- Secure Connectivity
