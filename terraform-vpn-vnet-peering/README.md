# Terraform VPN VNet Peering

Infrastructure as Code project for implementing secure Azure connectivity using VPN Gateway and VNet Peering.

## Technologies

- Microsoft Azure
- Terraform

## Resources Created

- VPN Gateway
- Virtual Network
- VNet Peering
- Network Security Groups

## Features

- Secure network connectivity
- Automated infrastructure deployment
- Azure networking automation

## Commands

```bash
terraform init
terraform validate
terraform plan
terraform apply
```
