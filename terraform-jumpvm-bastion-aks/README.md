# Terraform Jump VM Bastion AKS

Terraform-based Azure infrastructure project for secure access to Azure Kubernetes Service (AKS) using Jump VM and Azure Bastion.

## Technologies

- Microsoft Azure
- Terraform
- AKS
- Azure Bastion

## Resources Created

- Virtual Machine
- Azure Bastion
- AKS Cluster
- Virtual Network
- Network Security Groups

## Features

- Secure AKS access
- Bastion-based administration
- Infrastructure automation

## Commands

```bash
terraform init
terraform validate
terraform plan
terraform apply
```
