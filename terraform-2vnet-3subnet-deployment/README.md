# Terraform VNet Subnet Deployment

Infrastructure as Code (IaC) project for provisioning Azure networking resources using Terraform.

## Technologies

- Microsoft Azure
- Terraform

## Resources Created

- Virtual Network (VNet)
- Subnets
- Network Security Groups (NSG)

## Features

- Automated network provisioning
- Reusable Terraform configuration
- Infrastructure standardization

## Commands

```bash
terraform init
terraform validate
terraform plan
terraform apply
```
